# ProgettoSistemiDistribuiti

Realizzare un’applicazione cloud-based in grado di gestire, classificare e ricercare ticket di assistenza tecnica inviati dagli utenti. Il sistema dovrà consentire il caricamento o l’inserimento manuale di richieste di supporto relative a problemi software, hardware, servizi web, configurazioni di rete o malfunzionamenti generici.
L’utente potrà inserire un ticket compilando un modulo contenente almeno le seguenti informazioni: titolo del problema; descrizione dettagliata; categoria indicata dall’utente, se disponibile; livello di urgenza percepito; eventuale allegato testuale, ad esempio file .txt, .log, .json o .csv; data di apertura del ticket. In alternativa, il sistema potrà consentire il caricamento di un file contenente più ticket in formato CSV o JSON.
Una volta inserito o caricato il ticket, il sistema dovrà analizzare automaticamente il contenuto mediante tecniche di elaborazione del linguaggio naturale, con l’obiettivo di estrarre informazioni utili per la classificazione e la ricerca.
In particolare, il sistema dovrà essere in grado di: 1) estrarre parole chiave significative dalla descrizione del problema; 2) classificare automaticamente il ticket in una categoria, ad esempio rete, database, bug applicativo; configurazione, altro: 3) stimare un livello di priorità del ticket; 4) permettere la ricerca dei ticket per keyword, categoria, priorità, data o stato.
Il processo di analisi automatica potrà avvalersi di servizi cloud o librerie esterne che offrono funzionalità di NLP, classificazione o keyword extraction, tra cui: Amazon Comprehend; Azure AI Language Service; Google Natural Language API; librerie open-source come KeyBERT, YAKE, RAKE, spaCy, scikit-learn o altre soluzioni equivalenti.
